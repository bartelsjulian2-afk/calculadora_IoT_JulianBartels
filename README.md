# Calculadora de interés simple

Página web sencilla para calcular interés simple.

## Fórmula
`I = C × i × t`

- `I`: interés generado
- `C`: capital inicial
- `i`: tasa de interés anual en decimal (en la página se ingresa como porcentaje)
- `t`: tiempo expresado en años

El monto total es `C + I`.

## Uso local
Abre `index.html` en un navegador. No requiere instalación ni dependencias.
